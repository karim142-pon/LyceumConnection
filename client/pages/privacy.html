Настоящий документ описывает, какие данные собирает LyceumConnection, как они используются и какие права имеет пользователь.

1. Общие положения

LyceumConnection является социальной сетью для общения пользователей.

Оператор персональных данных:

  • Владелец: Шарипов Карим Наилевич
  • Email: karim27sh@gmail.com
  • Страна: Россия

2. Какие данные собираются

Регистрация

  • Имя
  • Фамилия
  • Логин
  • Пароль (только хеш)

Профиль

  • Биография
  • Аватар
  • Посты
  • Комментарии
  • Лайки

Технические данные

  • IP-адрес
  • User-Agent
  • JWT Cookie
  • Время входа

3. Цели обработки

  • авторизация;
  • работа аккаунта;
  • отображение публикаций;
  • защита сервиса;
  • предотвращение злоупотреблений.

4. Хранение данных

Данные хранятся в PostgreSQL.

Аватары — в server/uploads/avatars.

Изображения постов — в server/uploads/posts.

5. Передача данных

Мы не продаем персональные данные.

Передача возможна только по требованиям законодательства или для обеспечения работы инфраструктуры.

6. Безопасность

  • HttpOnly Cookie
  • JWT
  • Параметризованные SQL-запросы
  • Защита от SQL-инъекций
  • Защита от XSS
  • Валидация данных

7. Права пользователя

  • изменить данные;
  • удалить аккаунт;
  • получить сведения о своих данных;
  • отозвать согласие.
