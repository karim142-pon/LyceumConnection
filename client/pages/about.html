О проекте

LyceumConnection — современная учебная социальная сеть, созданная для общения пользователей и развития навыков веб-разработки.

Используемые технологии

  • HTML5
  • CSS3
  • JavaScript (ES Modules)
  • Node.js
  • Express
  • PostgreSQL
  • JWT
  • Git

Текущие возможности

  • регистрация;
  • авторизация;
  • создание публикаций;
  • лента пользователей.

План развития

  • лайки;
  • комментарии;
  • профили пользователей;
  • личные сообщения;
  • уведомления.
